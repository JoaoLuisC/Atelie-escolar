# Estrutura do Banco de Dados - Supabase

> Projeto: Ateliê da Escola
> Banco: Supabase / PostgreSQL

## Ordem de trabalho

1. Executar [supabase/schema.sql](supabase/schema.sql) no SQL Editor.
2. Criar o bucket de Storage, se for usar arquivos no Supabase.
3. Ajustar a API para usar Supabase em vez de qualquer banco legado.

## Tabelas principais

- `categories`
- `products`
- `orders`
- `order_items`
- `download_tokens`
- `download_logs`
- `profiles`
- `user_products`
- `settings`
- `page_views`

## Observação

O schema principal está em [supabase/schema.sql](supabase/schema.sql).
